# Lab 01 – Sentiment Analysis Using Traditional Machine Learning

## 1. Laboratory Session

**Module:** PUSL 3205 – Large Language Models and Generative AI

**Topic:** Sentiment Analysis Using Traditional Machine Learning

**Main Concepts:** Text Preprocessing, Bag of Words (BOW), and Machine Learning

**Programming Language:** Python

## 2. Objective

To practise basic Natural Language Processing (NLP) tasks by preprocessing text data, exploring sentiment-labelled sentences, training a traditional machine learning model, and evaluating its performance.

## 3. Tasks and Implementation

The following activities will be completed during this practical:

- [ ] Download and load the sentiment-labelled sentences dataset.
- [ ] Perform basic text preprocessing:
  - Convert text to lowercase.
  - Remove unnecessary characters and punctuation.
  - Remove extra whitespace.
  - Create a clean-text column.
  - Compare original and preprocessed text.
- [ ] Explore the text data:
  - Display positive and negative examples.
  - Identify frequently occurring words.
  - Observe differences between positive and negative reviews.
- [ ] Split the dataset into training and testing sets.
- [ ] Create a Bag of Words (BOW) representation.
- [ ] Train a machine learning model (e.g., SVM or Logistic Regression).
- [ ] Evaluate the model using accuracy, precision, recall, and F1-score.
- [ ] Test the model using a new sentence.
